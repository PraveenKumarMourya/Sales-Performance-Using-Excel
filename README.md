# Sales-Performance-Using-Excel
My First Excel Dashboard Project – A Deep Dive into Sales Performance! 📊✨

I’m thrilled to share my very first Excel dashboard project with the LinkedIn community! 🎉 I’ve spent a lot of time learning and applying different Excel techniques to create a dynamic dashboard that analyzes and visualizes sales performance for a team of sales executives.
Here’s what the dashboard offers:
🔹 Top 5 Sales Executives by Total Sales
🔹 Top 5 Sales Executives by Target Hit %
🔹 Top 5 Sales Executives by Away from Target %
🔹 Region-specific Insights: A Region Slicer linked across four different dashboards, allowing dynamic filtering of data based on region.
Key Features:
Pivot Tables: Two pivot tables showcasing top performers in different categories.
Charts: A mix of bar, line, and pie charts to visually represent the sales trends and performance metrics.
Macros: Using macros to automate the filtering process for real-time insights.
